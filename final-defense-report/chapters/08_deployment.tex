\section{Local Deployment}

\subsection{Single-Command Startup}

The entire platform launches with a single command:

\begin{lstlisting}[language=bash, caption={Platform startup}]
make start-NeXo
\end{lstlisting}

This command:
\begin{enumerate}
    \item Builds and starts all Docker containers via \texttt{docker compose up -d --build}
    \item Starts Ollama LLM server in background
    \item Starts Next.js dashboard on port 3001
    \item Opens the browser to the dashboard URL
\end{enumerate}

\subsection{Service Health Verification}

\section{Docker Configuration}

\subsection{Base Images}

All Python services use \texttt{python:3.11-slim} as the base image, providing a minimal footprint (~150MB) while including the full Python 3.11 runtime.

\subsection{Health Checks}

Services define health checks to ensure dependency ordering:

\begin{itemize}
    \item \texttt{postgres}: \texttt{pg\_isready} every 5 seconds
    \item \texttt{minio}: HTTP health endpoint
    \item \texttt{ai-service}: Depends on healthy postgres
    \item \texttt{pipeline-worker}: Depends on healthy postgres, minio, and started ai-service
\end{itemize}

\section{Huawei Cloud Stack Deployment}

\subsection{Migration Strategy}

The platform is designed for direct portability to \gls{hcs} with minimal configuration changes:

\begin{enumerate}
    \item \textbf{Object Storage}: Replace MinIO endpoint URL with \gls{obs} endpoint. The S3 API is fully compatible.
    \item \textbf{Database}: Replace PostgreSQL connection string with \gls{rds} for PostgreSQL endpoint.
    \item \textbf{Compute}: Push Docker images to SWR (Software Repository) and deploy on \gls{ecs} instances.
    \item \textbf{Monitoring}: Replace Prometheus/Grafana with Application Operations Management (AOM).
\end{enumerate}

\subsection{Environment Configuration}

All service-specific configuration is passed via environment variables, enabling zero-code-change deployment:

\begin{lstlisting}[language=bash, caption={HCS environment variables}]
# Local (Docker Compose)
S3_ENDPOINT=http://minio:9000
DATABASE_URL=postgresql://telecom:pw@postgres:5432/telecom_intel

# Huawei Cloud Stack
S3_ENDPOINT=https://obs.cn-north-4.myhuaweicloud.com
DATABASE_URL=postgresql://telecom:pw@rds-xxx.rds.myhuaweicloud.com/telecom_intel
\end{lstlisting}
