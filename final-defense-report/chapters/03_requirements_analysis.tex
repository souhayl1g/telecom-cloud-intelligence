\section{Host Organization}

\subsection{Huawei Technologies Tunisia}

Huawei Technologies Co., Ltd. is a global leader in ICT infrastructure and smart devices, serving over three billion people in more than 170 countries. Huawei Tunisia operates within the Cloud IT / Sales-Solution department, providing cloud infrastructure, CEM solutions (SmartCare), and digital transformation services to North African telecommunications operators, including Tunisie Telecom.

\subsection{Project Context}

This project was initiated as part of a six-month engineering internship (February--July 2026) to address the need for an intelligent operations platform that bridges the gap between network performance monitoring (CEM) and business intelligence (CVM) for Tunisie Telecom.

\section{Use Case Diagram}

The system supports three primary actors:

\begin{enumerate}
    \item \textbf{Network Operator}: Views dashboard, reviews agent actions, interacts with L4 Agent chat
    \item \textbf{Data Pipeline}: Automated data ingestion, ML inference, and persistence (every 120 seconds)
    \item \textbf{System Administrator}: Manages users, monitors platform health, configures pipeline parameters
\end{enumerate}
